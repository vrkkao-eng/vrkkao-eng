# Victor Kao

**Applied AI & Knowledge Engineering · Legal AI · Knowledge Graphs · Reliable AI**

I build systems at the intersection of **AI engineering, knowledge representation, and complex regulated domains**. My background combines law and ICT, digital humanities, ontology/knowledge-graph engineering, and current study in artificial intelligence (Speech & Language Technology).

My main interest is turning difficult domain requirements into **inspectable, testable, and usable systems**.

## Featured work

### [MAILO Legal AI Engine](https://github.com/vrkkao-eng/mailo-legal-ai-engine)
**Python research pipeline · knowledge engineering · validation**

Public Python package/CLI for structured findings, RDF/JSON-LD export, SPARQL execution, SHACL validation, reproducible reports, automated tests, and GitHub Actions CI.

**Stack:** Python 3.11+ · RDFLib · pySHACL · SPARQL · JSON-LD · pytest · GitHub Actions · optional Anthropic tool loop

### [Adaptive KG Reasoning](https://github.com/vrkkao-eng/adaptive-kg-reasoning)
**Incremental reasoning · dynamic knowledge graphs · reproducible evaluation**

Experimental Python prototype comparing full recomputation with incremental maintenance over dynamic knowledge-graph windows. Current benchmarks test exact result equivalence while measuring maintenance cost across different window-overlap regimes.

**Stack:** Python · RDFLib · OWL-RL · pytest · benchmark/evaluation pipelines

### [MAILO — Medical AI Legal Ontology](https://github.com/vrkkao-eng/Mailo-ontology)
**Knowledge graph · OWL 2 · SHACL · EU medical-AI regulation**

Canonical knowledge-model repository for representing obligations and legal relationships across EU medical-AI regulation, with machine-executable SHACL constraints linked to legal sources and CJEU case law.

### [NomadSpot Taiwan](https://github.com/vrkkao-eng/NomadSpot-Taiwan)
**Backend for Frontend · API integration · deployment**

Four-person web application for discovering work-friendly cafés in Taiwan. My contribution focused on frontend/backend server setup, the Express BFF, and external API integration.

**Stack:** Node.js · Express · Leaflet · multi-source APIs · OAuth token caching · fallback handling · Vercel
